# Buckley Facility Operations Monitor

A test decision-support dashboard for Buckley Space Force Base that combines official weather, aviation, road, wildfire, and emergency-alert data into facility and commute hazard information.

It displays **NORMAL, WATCH, ACTION, or CLOSE CRITERIA MET** for facility conditions and provides a separate essential-personnel route assessment.

**This is a test decision-support tool, not an official Buckley closure or emergency-notification system.**
